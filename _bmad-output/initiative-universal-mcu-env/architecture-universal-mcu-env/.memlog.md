- (decision) Build stack axis [AD-11]: each pack declares a language-keyed stacks map (source language -> build stack id); the resolved stack, never the language string, selects template family, toolchain image, and build command. A missing (pack, language) pair is an error, not a default.
- (decision) Split probe port [AD-12]: FlashPort (render_argv/flash/proof_for/last_transcript) and DebugPort (debug/monitor); a backend always implements FlashPort and implements DebugPort only where the device supports attach; the CLI fails a verb whose port is unimplemented rather than fabricating a handle.
- (decision) Family block validators ship with device truth [AD-13]: core owns only the frame, the registry mechanism, and dispatch; validators live alongside packs/. A new brand adds validators plus pack sections plus adapters and requires zero core diffs (AD-1 acceptance).

The pack probe block is the single source of connection requirements; the shim merges it with CLI selectors; autodetect IDs are registered per family, not hardcoded in cli/.
